# Security Policy

## Supported versions

Security fixes target the latest commit on `main` and the latest release tag. The Copilot Chat provider extensions pin the kit as a git submodule; a fix reaches users when each extension bumps its submodule and publishes a release.

## Reporting a vulnerability

Email [security@nibras.co](mailto:security@nibras.co). Do not open a public issue or discussion.

Include, when applicable:

- A concise description and potential impact
- Affected kit commit or tag, and the consuming extension and version
- Reproduction steps or a proof of concept
- Relevant logs with API keys, prompts, and personal data removed

You should receive an acknowledgment and a request for any missing details. Please allow time for investigation and releases of the affected extensions before public disclosure. If the report is not security-sensitive, use the normal issue templates instead.
